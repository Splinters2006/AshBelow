# Unity project

This is a Unity 6 project.

## Rules

- C# scripts belong in Assets/Scripts.
- Follow normal Unity C# conventions.
- Prefer components and ScriptableObjects over large monolithic classes.
- Do not modify generated Unity files.
- Do not edit Library/, Temp/, Logs/, or obj/.
- Preserve Unity .meta files.
- Avoid unnecessary changes to scene YAML.
- Check existing scripts before creating duplicate systems.
- Keep scripts compatible with the Unity version used by this project.
